Anurag Nepal — AI Experiments Lab

Four complete studies where statistics meets modern AI: each one is a real experiment with honest uncertainty, published as an open GitHub repo with code, notebooks, and full write-ups.

Every dashboard below is self-contained and interactive. Each project also lives on GitHub with source code, executed notebooks, and a full report.

Can an LLM Replace Human Annotators?

Can an LLM do a human annotator's job? I had Gemini classify 250 biomedical abstracts and scored it like a real reliability study, with confidence intervals, Cohen's kappa, a calibration check, and a head-to-head against a TF-IDF baseline plus a cost comparison.

View dashboard GitHub repo

RAG Evaluation Lab

A RAG evaluation run like a real experiment. I built a TF-IDF retriever and Gemini generator over 500 PubMed abstracts and tested chunk size, top-k, and query rewriting in a full factorial design, analyzed with ANOVA and effect sizes.

View dashboard GitHub repo

Synthetic Data Tradeoffs

How much fidelity, utility, and privacy do you lose when you train on synthetic data? I compared a from-scratch Gaussian copula against LLM row synthesis on the breast cancer dataset, including a membership-inference attack.

View dashboard GitHub repo

Double Machine Learning for a Causal Effect

Estimating the causal effect of 401(k) eligibility on household wealth. I compare naive OLS, OLS with controls, propensity-score matching, and double machine learning with cross-fitting, each with honest 95% confidence intervals.
