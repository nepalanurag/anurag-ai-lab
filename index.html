Anurag Nepal's AI Experiments Lab

Six projects on statistics and AI. Each one is on GitHub with code, an executed notebook, and a full write-up.

Every dashboard below is self-contained and interactive.

Can an LLM Replace Human Annotators?

I had Gemini classify 248 biomedical abstracts and scored it like a reliability study: confidence intervals, Cohen's kappa, a calibration check, a head-to-head against a TF-IDF baseline, and a cost comparison.

View dashboard GitHub repo

RAG Evaluation Lab

I built a TF-IDF retriever and Gemini generator over 579 PubMed abstracts and tested chunk size, top-k, and query rewriting in a 2x2x2 factorial design, analyzed with ANOVA and effect sizes.

View dashboard GitHub repo

Synthetic Data Tradeoffs

I compared a from-scratch Gaussian copula against LLM row synthesis on the breast cancer dataset, measuring fidelity, utility, and privacy, including a membership-inference attack.

View dashboard GitHub repo

Double Machine Learning for a Causal Effect

Estimating the causal effect of 401(k) eligibility on household wealth. I compare naive OLS, OLS with controls, propensity-score matching, and double machine learning with cross-fitting, each with honest 95% confidence intervals.

View dashboard GitHub repo

Bayesian A/B Testing Calculator

An interactive calculator for A/B tests using Beta-Binomial posteriors. Enter your successes and trials, get posterior distributions, probability that B beats A, and expected loss — no p-values needed.

View dashboard GitHub repo

Honest Confidence Sets for LLM Answers

Split conformal prediction applied to multiple-choice QA. I calibrate prediction sets on MMLU questions so they contain the right answer with a guaranteed coverage rate, and show where the guarantee breaks.

View dashboard GitHub repo
