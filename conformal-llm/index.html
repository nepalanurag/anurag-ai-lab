conformal-llm

Honest confidence sets for LLM answers

I had a small open language model answer 416 multiple-choice science questions, then used split conformal prediction to turn its output probabilities into answer sets that contain the correct option at least 90% of the time. Guaranteed by math, checked on held-out data.

How it works, in four steps

  1. Score. For each question the model assigns a probability to each option (its next-token probabilities for A/B/C/D). The nonconformity score is 1 − p(correct option): 0 when the model is sure and right, near 1 when it is confidently wrong.
  2. Calibrate. On 208 held-out questions I take the 90th percentile of those scores (with the finite-sample correction ⌈(n+1)(1−α)⌉/n). Call it q̂.
  3. Threshold. For a new question, the prediction set is every option whose score is at most q̂.
  4. Guarantee. If calibration and new questions are exchangeable, the true option lands in the set with probability at least 1−α — whatever the model, whatever the data distribution. The model's quality only decides how large the sets have to be.

Two scores, compared honestly

LAC (Sadinle, Lei & Wasserman 2019) thresholds 1 − p directly. APS (Romano, Sesia & Candès 2020) accumulates options from most to least probable and thresholds the running total, which adapts set sizes to each question's difficulty. Both keep the guarantee; the comparison below shows whether adaptivity actually buys smaller sets here.

Honest caveats

  • The guarantee is marginal: averaged over questions, not per question. A set on one hard question can still miss; the subject table above checks the obvious slices.
  • It assumes new questions come from the same distribution as the calibration set (exchangeability). Calibrate on stats questions, deploy on medical ones, and the promise is void.
  • Coverage is not calibration: a set of all four options covers 100% of the time and tells you nothing. Watch the mean set size alongside coverage.
